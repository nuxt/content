# Installation

Étendez le layer depuis votre `nuxt.config.ts` :

```ts
export default defineNuxtConfig({
  extends: ['./layer'],
})
```

Comme `content/fr/docs` existe, la collection `docs_fr` du layer est montée sur `/fr/docs`.
