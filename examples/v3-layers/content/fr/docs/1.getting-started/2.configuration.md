# Configuration

Le `content.config.ts` du layer est exécuté au build avec `useNuxt()` : il peut donc adapter ses
collections au projet qui l'utilise (locales i18n, page d'accueil personnalisée, dossier `docs`, …).

Ajoutez un `content.config.ts` dans le projet pour déclarer d'autres collections. Une collection
portant le même nom qu'une collection du layer la remplace.
