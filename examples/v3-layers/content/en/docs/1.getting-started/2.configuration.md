# Configuration

The layer's `content.config.ts` runs at build time with `useNuxt()`, so it can adapt its
collections to the consuming project: the i18n locales, a custom landing page, a `docs` folder, …

Add a `content.config.ts` in the project to declare more collections. A collection with the same
name as one from the layer replaces it.
