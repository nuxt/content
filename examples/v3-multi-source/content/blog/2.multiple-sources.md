# Multiple Sources

`content.config.ts` declares two collections:

- `docs` → `github.com/nuxt/content` (`docs/content/docs`), mounted on `/docs`
- `blog` → local `content/blog` directory, mounted on `/blog`

Nothing else is needed: the module picks up `content.config.ts` automatically
and each collection can be queried by name:

```ts
const posts = await queryCollection('blog').all()
const nav = await queryCollectionNavigation('docs')
```
